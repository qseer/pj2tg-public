# 课程同步仓库

这里是我们日常课程的同步代码仓库。每次上完课，我会把当天的题目、题单、题解和参考代码归档到一个以日期开头的目录里（比如 `0612-树与图论专题/`），方便大家课后回看。

## 这里有什么

- **今天的题目和题单**：当天专题的题目列表、链接、课内课后的安排
- **题解汇总**：每道题的一句话题解、算法标签、对应的参考代码文件
- **参考代码**：题目对应的 C++ 代码，命名一般是 `题号-题名.cpp`

按目录名顺序往下翻，就是按上课时间排的。想找以往的某节课，直接看日期就行。

## 怎么用

- 课上跟不上的、课后想再过一遍的，进对应日期目录看 `problems.md`（题单）和 `solutions.md`（题解汇总）
- 自己写完之后想对照参考实现，再打开同目录下的 `.cpp` 文件
- **不建议直接抄**。每道题先自己想、自己写到能交上去（哪怕是部分分），再来对答案，进步才会快

## 也鼓励大家自己建一个仓库

学竞赛到一定阶段，自己整理过的笔记和题解，比任何老师发的资料都更值钱。强烈推荐每个人都开一个属于自己的 OI 仓库：

- 在 GitHub 或 Gitee 上免费建一个 repo
- 按你自己舒服的方式组织目录（按专题、按日期、按题号都行）
- 每写完一道题，把代码和一两句"我当时怎么想的"一起 commit 进去
- 哪怕一开始很简陋也没关系，关键是养成"做完就整理"的习惯

半年回头看，你会发现自己的成长远比想象的快。

## 路线说明

我们现在的节奏是**先把普及组吃透，再过渡到提高组**。所以你会看到题单里既有 CSP-J / GESP 路线的基础题，也开始穿插一些 DP、图论这种提高组常考的专题。循序渐进，不要急——

- 普及阶段：把模拟、贪心、二分、搜索、基础 DP 这几块练扎实
- 过渡阶段：树形 DP、图论入门、记忆化搜索这些桥梁专题
- 提高阶段：再往更深的 DP、数据结构、图论算法走

每节课都是这条路上的一小步，跟着走就行。有问题随时问。
