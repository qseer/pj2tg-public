# 小信的符文阵列

## 题目描述

**时间限制：1000ms 空间限制：524288kB**

小信发现了一个环形符文阵列，其中有数字和字符，字符中有 `+, -, *, ?`。

现在我们从第一个数字开始，顺时针记录整个串并忽略最后一个字符，接下来从第二个数字开始，一直到以每个数字作为开头记录每一个串。对于每个记录下来的串，我们执行如下操作：

1. 将每个 `?` 替换为 `+, -, *` 中的一个，穷举所有可能我们将得到很多不同的表达式
2. 以任意优先级顺序计算每个表达式，将会得到多个运算结果
3. 从这些运算结果中，选择最大最小值，将最小值数字串与最大值数字串拼接，得到该序列的密码。

将每一个序列得到的密码，按照生成的顺序拼接，就是符文阵列最优的表达。

## 输入格式

第一行包含正整数 $k$，表示序列中（数字，符号）对的数量。

第二行包含 $2k$ 个元素：$n_1, s_1, n_2, s_2, ..., n_k, s_k$，其中 $n_i$ 为数字，$s_i$ 为 `+`、`-`、`*` 或 `?` 符号。

## 输出格式

输出一行，符文阵列的最优表达。

## 样例

### 样例输入 1

```
5
1 ? 5 + 0 ? -2 - -3 *
```

### 样例输出 1

```
914710203014163336
```
