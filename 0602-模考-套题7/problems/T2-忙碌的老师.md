# 忙碌的老师

## 题目描述

信友队每周都有 $n$ 节课，每个课都有开始与结束时间，第 $i$ 个课开始时间是 $A_i$，结束时间是 $B_i$，每个课都要有对应的老师上课。每个老师同一时间都只能上一个课，并且要全程参与，所以如果有某个老师上第 $i$ 节课，那他在 $[A_i, B_i]$ 这个时间段就不能上别的课了。为了能够顺利地把 $n$ 节课上完，问最少需要多少名老师。

## 输入格式

第一行输入一个 $n$ $(1 \le n \le 10^5)$。

接下来 $n$ 行，每行两个数，$A_i$ $B_i$ $(-10^9 \le A_i \le B_i \le 10^9)$。

## 输出格式

输出一行一个数，代表至少需要几个老师。

## 样例

### 样例输入 1

```
3
-1 1
2 4
3 5
```

### 样例输出 1

```
2
```
