# 小信的su7

## 题目描述

小信买了一辆小米 su7，可是他发现充电是一大难题。我们可以将电池看做是由 $n$ 个电瓶组成，每个电瓶的电量上限是 $a_i$，每消耗一个单位的电可以前进 1 公里。行驶过程中小信可以选择消耗任意电瓶的电，且我们认为电量都是完整按照一个单位来消耗。

现在小信想试试 su7 的性能，他将所有电池充满电，在这趟路程中，小信会经过 $m$ 个充电站，第 $j$ 个充电站距离起点 $x_j$ 公里，仅能为第 $t_j$ 块电池充电。每个充电站供应的电量无限。

因为小信想来一场不回头的旅行，所以我们规定只能前进不能后退，小信想请你帮他算算，最多能开车走多远。

## 输入格式

第一行包含两个整数 $n, m$，表示电瓶数量和充电站的数量。

第二行包含 $n$ 个整数 $a_1, a_2, ..., a_n$，表示每块电池的容量。

接下来的 $m$ 行每行包含两个整数 $x_j, t_j$，表示出发点到第 $j$ 个充电站的距离的和它可以充电的电池。

保证 $1 \le x_1 < x_2 < ... < x_m \le 10^9$。

## 输出格式

输出一个整数，表示车辆可以行驶的最远距离。

## 样例

### 样例输入 1

```
3 1
3 3 3
8 1
```

### 样例输出 1

```
12
```
