# 石头布

## 题目描述

你和对手都只有两种出拳方式：石头（`g`）和布（`p`），规则是，赢了加一分，平局不得分，输了扣一分。

现在你已经预测到对手的出拳方式。问你在满足限制条件的情况下，能得到的最大分数。

限制条件是，假设你到第 $i$ 局共出了 $x_i$ 次石头，$y_i$ 次布，对于任意的第 $i$ 局都要能满足 $x_i \ge y_i$。

## 输入格式

输入一行由 `'g'` 和 `'p'` 组成的字符串 $s$，表示预测的对手的出拳方式，$s$ 的长度不超过 $10^5$。

## 输出格式

输出你能得到的最大分数。

## 样例

### 样例输入 1

```
ggppgggpgg
```

### 样例输出 1

```
2
```
