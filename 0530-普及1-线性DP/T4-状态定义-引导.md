# T4 最长公共子序列 — 状态定义引导稿（心法复用）

> 用途：把 T3 教过的心法"状态被转移*逼*出来"再用一次。
> 这次的"撞墙"形式不同——T3 是"信息不够"，T4 是"两个序列只锚定了一个"。

## 例子

```
s = "abcbdab"
t = "bdcaba"
答案：4   （"bdab" 或 "bcba"）
```

---

## 第一回合：复用 T3 的心法

> 提问："参考 LIS，我们应该怎么定义状态？"

学生大概率会回答两种：

### 学生回答 A：`dfs(i) = s[1..i] 与 t 的 LCS 长度`

让他试着写转移：

```cpp
// dfs(i) = s 前 i 个字符与整个 t 的 LCS
int dfs(int i)
{
    if(i == 0) return 0;
    // 选 s[i]：要在 t 里找一个和 s[i] 相同的字符接上去——可是 t 的哪个位置？我不知道
    // 不选 s[i]：dfs(i-1)
    return max(dfs(i-1), /* 选 s[i] 的情况 */ ???);
}
```

**和 T3 撞的是同一堵墙**：`dfs(i-1)` 只告诉你"前 `i-1` 个能凑出多长的 LCS"，但没告诉你*在 `t` 里用到了哪里*——所以你不知道 `s[i]` 能从 `t` 的哪个位置之后开始匹配。

> "T3 是不知道前面 LIS 的末尾值，这里是不知道前面 LCS 在 `t` 里用到了哪儿。**症状一样：状态信息量不够。**"

### 学生回答 B（顺势引导）：那就把 `t` 也参数化

```cpp
// dfs(i, j) = s 前 i 个字符与 t 前 j 个字符的 LCS 长度
```

> "T3 我们补了'必须以 a[i] 结尾'这个约束；这里我们补的是'`t` 只用到前 `j` 个'。本质都是**给子问题划清边界**。"

---

## 第二回合：推转移

固定状态 `dfs(i, j)` 后，问："最后一个字符 `s[i]` 和 `t[j]` 之间是什么关系？"

**只有两种情形**：

- `s[i] == t[j]`：那一定可以把它俩配成 LCS 里的最后一对——更短不会更优。
  → `dfs(i, j) = dfs(i-1, j-1) + 1`
- `s[i] != t[j]`：它俩至少有一个用不上（不可能同时出现在 LCS 末尾）。
  → `dfs(i, j) = max(dfs(i-1, j), dfs(i, j-1))`

```cpp
int dfs(int i, int j)
{
    if(i == 0 || j == 0) return 0;
    if(s[i-1] == t[j-1]) return dfs(i-1, j-1) + 1;
    return max(dfs(i-1, j), dfs(i, j-1));
}
```

可以画一棵 3 层递归树，让学生看出 `dfs(i-1, j-1)`、`dfs(i-1, j)`、`dfs(i, j-1)` 在不同分支里反复出现——**重叠子问题再次出现**。

加 `memo[i][j]`（初始化 `-1`，因为 LCS 长度可能为 0），就是 T4 的记忆化版本。

---

## 第三回合：改写成 DP

依赖关系：`dp[i][j]` 只依赖 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]`——都在它的"上方"和"左方"。

→ 按 `i` 从 1 到 `n`、`j` 从 1 到 `m` 双重循环填表，正好满足依赖顺序：

```cpp
for(int i = 1; i <= n; ++i)
    for(int j = 1; j <= m; ++j)
    {
        if(s[i-1] == t[j-1]) dp[i][j] = dp[i-1][j-1] + 1;
        else                 dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
cout << dp[n][m];
```

> "和 T1 一模一样的流水线：DFS → memo → for 循环填表。区别只在状态从一维 `(i,j)` 变成两维 `(i,j)`。"

---

## 教学收尾：心法的第二次确认

到这里，学生应该能自己总结出来：

| 题 | 撞的墙 | 补什么 |
|---|---|---|
| T3 LIS | 不知道前面 LIS 的末尾 | 多加约束："必须以 `a[i]` 结尾" |
| T4 LCS | 不知道前面 LCS 在 `t` 里用到了哪 | 多加一维参数：`t` 的前 `j` 个 |

**两种"补"的方式不同，但起因相同**——都是"现有状态不足以表达转移"。

> "以后看到任何 DP 题，第一步永远是先写一个最自然的 DFS；写不出转移的那一刻，状态长什么样就明白了。"

---

## 顺带：T4 比 T3 更适合反过来"先看 DP 表"的同学

如果有学生已经看过 DP 写法，可以让他对照：`dp[i][j]` 的二维表就是 `memo[i][j]`，填表顺序就是"先填左上，再填右下"。两者**完全等价**，只是叙述视角不同——一个是"我*请求*这个值"，一个是"我*主动算出*所有值"。
