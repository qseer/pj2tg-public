# T1 方格取数 — 状态定义引导稿（热身）

> 用途：作为整堂课的**第一道题**，让学生在最容易的题上把"暴力 DFS → 加 memo → 改写成 DP"这条流水线走通一遍。
> 这道题的状态学生几乎一次就能想对，所以**重点不在状态设计，而在演示流水线**。

## 题面回顾

`n × n` 方格，每格有非负权值。从 `(1,1)` 走到 `(n,n)`，每步只能向右或向下，求路径上权值之和的最大值。

---

## 第一步：从"答案"反推状态

> 提问："要求的是什么？"
> 答："从 `(1,1)` 走到 `(n,n)` 的最大和。"

> 再问："那有没有办法用一个函数把这件事描述出来？"

```cpp
// dfs(i, j) = 从 (1,1) 走到 (i,j) 的最大和
```

**几乎所有学生第一次就能写对。** 这正是要的——让他们建立信心："原来状态就是把答案里的具体数字换成参数"。

---

## 第二步：推转移

> "走到 `(i,j)` 之前的最后一步在哪？"
> 答："要么从上面 `(i-1, j)` 走下来，要么从左边 `(i, j-1)` 走过来。"

转移直接落地：

```cpp
int dfs(int i, int j)
{
    if(i < 1 || j < 1) return 0;
    if(i == 1 && j == 1) return grid[1][1];
    return max(dfs(i-1, j), dfs(i, j-1)) + grid[i][j];
}
```

跑一遍样例，**对的**。但有问题：

> "这样写在 `n = 1000` 时会怎样？"

让学生估算：每个格子有两个分支，深度 `2n`，复杂度 `O(2^(2n))`，秒挂。

---

## 第三步：发现重复子问题

画一个 3×3 网格，手动展开递归树前两层：

```
                dfs(3,3)
               /        \
          dfs(2,3)      dfs(3,2)
          /    \         /    \
     dfs(1,3) dfs(2,2) dfs(2,2) dfs(3,1)
                 ↑         ↑
                 └─── 重复！───┘
```

> "`dfs(2,2)` 被算了两次。如果网格再大，同一个 `(i,j)` 会被算成千上万次——但答案永远是同一个。"

**加 memo**：

```cpp
int memo[maxn][maxn];  // 初始化为 -1 表示未算过（本题权值非负，安全）

int dfs(int i, int j)
{
    if(i < 1 || j < 1) return 0;
    if(i == 1 && j == 1) return grid[1][1];
    if(memo[i][j] != -1) return memo[i][j];
    return memo[i][j] = max(dfs(i-1, j), dfs(i, j-1)) + grid[i][j];
}
```

复杂度从 `O(2^(2n))` 一下降到 `O(n²)`——每个 `(i,j)` 只算一次。**这就是记忆化搜索。**

---

## 第四步：改写成 DP（关键一步）

> "既然每个 `(i,j)` 只算一次，那我能不能不用递归，直接按某个顺序*主动*把所有 `(i,j)` 都算出来？"

观察：`dfs(i,j)` 依赖 `dfs(i-1,j)` 和 `dfs(i,j-1)`——也就是说，**只要先算完上一行和这一行左边的格子，当前格子就能算**。

那就按 `i` 从 1 到 `n`、`j` 从 1 到 `n` 的顺序填表：

```cpp
for(int i = 1; i <= n; ++i)
    for(int j = 1; j <= n; ++j)
        dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + grid[i][j];
cout << dp[n][n];
```

把两段代码并排放给学生看：

| 记忆化搜索 | DP |
|--|--|
| `dfs(i, j)` 这个函数 | `dp[i][j]` 这个数组 |
| 递归调用 `dfs(i-1, j)` | 直接读 `dp[i-1][j]` |
| 由 `memo` 防重复 | 由 *填表顺序* 防重复 |
| 自顶向下（被需要才算） | 自底向上（提前全算好） |

> "本质是同一件事——状态、转移完全一样，只是计算的顺序不同。"

---

## 教学收尾

留下两个结论，T2/T3/T4 全程都会用：

1. **写 DP 的流水线**：先想"状态 = 把答案参数化" → 写 DFS 转移 → 发现重叠子问题 → 加 memo → 按依赖顺序改成 for 循环。
2. **DP 数组 = 记忆化的 memo**：它们存的东西完全一样。所谓"DP 状态定义"，就是"那个 DFS 函数的返回值定义"。

> 这两条建立好以后，T3 的"为什么状态非要带'以 i 结尾'"才听得懂——因为它在问"DFS 函数的参数得带什么，转移才写得出来"。
