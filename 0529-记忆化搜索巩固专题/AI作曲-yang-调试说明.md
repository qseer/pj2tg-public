# 调试说明

你的 DP 思路完全正确，不用怀疑递推——按"当前音符 / 前驱音符 各自是固定还是自由"分四种情况讨论，这套分类是严谨的，甚至比标程还省事。

问题只出在一个地方：**取值的下标基准对不上**。题目里音符取值是 `1..m`，固定音符 `a[i]` 给的也是 `1..m`，可你把矩阵读进了 `qwq[0..m-1][0..m-1]`、自由音符也按 `0..m-1` 枚举——于是固定音符按 `1..m` 取下标、自由音符按 `0..m-1` 取下标，两套编号根本对不齐：固定音符会去读第 `m` 行/列（你压根没填，全是 0），而本该是第 1 行的数据被错存到了下标 0。直接后果是——**全是自由音符的数据能蒙对（因为自己跟自己自洽地用了 0..m-1），但只要出现一个固定音符就会算错**，这也是你可以拿来自测的判据。

修复也很简单，把下面四处统统从 `0..m-1` 改成 `1..m` 即可，递推体一行都不用动：①矩阵读入的双重循环；②`a[i]>0 && a[i-1]<0` 里枚举前驱 `k` 的循环；③`a[i]<0 && a[i-1]<0` 里枚举 `j` 和 `k` 的两层循环；④`a[i]<0 && a[i-1]>0` 里枚举 `j` 的循环；⑤最后统计答案的 `for` 循环。
