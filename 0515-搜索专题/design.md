# 0515 搜索专题 · 教学设计骨架

## 一、课程主线

**核心思想 → 基本模板 → 经典例题（含剪枝种子）→ 为 DP 铺垫 → 后续进阶**

关键修订：在排列/组合/圆排列之外补 **子集枚举**；在斗地主之前加一道 **干净的记忆化过渡题**；剪枝在数独/八皇后处现场引入，不全推到下节。

---

## 二、教学设计表

| 环节 | 时长 | 例题 | 对应知识点 | 教学目的 |
|---|---|---|---|---|
| 开场暖身 | 5' | 抽奖 | 枚举 | 建立"搜索 = 枚举所有可能"的直觉 |
| 核心思想 | 10' | — | 枚举 / 嵌套层数可为变量 / DFS vs BFS 一句话铺垫 | 破除"搜索 ≈ 回溯"的窄印象 |
| 模板 1 · 全排列 | 10' | 全排列 | 排列模板、used 数组 | 最干净的递归骨架 |
| 模板 2 · 组合 | 10' | 选数 | 组合模板、起始下标 | 与排列对比，理解"顺序无关" |
| 模板 3 · 子集枚举 ⭐ | 10' | 子集和 / 输出所有子集 | 2^n 枚举、选与不选 | **新增**，为状压 DP 埋种子 |
| 模板 4 · 圆排列 | 5' | 圆桌座次 ⭐ | 固定一元消除旋转对称 | **补例题**，让模板落地 |
| 例题 1 · 约束满足 | 15' | 八皇后 | 全排列 + 冲突判断 + **可行性剪枝** | 朴素版 → 加剪枝的现场迭代 |
| 例题 2 · 约束满足进阶 | 15' | 数独 | 行/列/宫剪枝、候选集 | 体验"不剪枝跑不动"，剪枝即生产力 |
| 例题 3 · 图上搜索 | 15' | 迷宫 | DFS / BFS 对比、最短路用 BFS | 打开第二条腿 |
| 过渡题 ⭐ | 15' | 数字三角形 / 矩阵最长递增路径 | **记忆化搜索**、重复子问题 | **新增**，从搜索平滑过渡到 DP |
| 为 DP 铺垫 | 10' | （回看过渡题） | 状态定义、子问题分解、memo | 显式点出"记忆化 = 自顶向下 DP" |
| 综合互动 | 15' | 斗地主 | 复杂状态设计、组合搜索 | 综合演练，体会状态爆炸 |
| 后续进阶预告 | 5' | — | 系统化剪枝策略、双向搜索 | 留钩子，承接下节 |

⭐ = 相对原大纲新增 / 补充的内容

## 四、节奏建议

- 总时长约 **140 分钟**，按实际课时可裁掉圆排列或斗地主之一。
- 八皇后与数独务必现场跑"无剪枝版本"，让学生看到 TLE / 卡顿，剪枝的动机才立得住。
- 过渡题是全课承上启下的枢纽，不要省。
